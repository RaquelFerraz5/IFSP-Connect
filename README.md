## Autor
Raquel de Oliveira Ferraz

## Curso
Engenharia de Computação — Instituto Federal de São Paulo (IFSP), Câmpus Guarulhos

## Objetivo do Projeto
O IFSP Connect é um website institucional desenvolvido como projeto prático da
disciplina de Desenvolvimento Front-End, ministrada pela Prof.ª  Lucineide Pimenta. O projeto
tem como objetivo aplicar, de forma progressiva, os conceitos de estruturação, estilização e
interatividade web, evoluindo a cada missão até se tornar uma aplicação web completa — com
páginas institucionais, catálogo de cursos, agenda de eventos, galeria de imagens, formulário
de contato e interface responsiva.

## Tecnologias Utilizadas
- **HTML** — estruturação semântica das páginas
- **CSS** — estilização visual e responsividade
- **JavaScript** — interatividade e validação de formulários
